## 🚀 Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/daniel-comas/your-repo-name.git
   ```
2. Open the folder in VS Code (or your editor of choice).
3. Right-click `index.html` and select **Open with Live Server** (recommended — some features like the download link and YouTube embed behave better over `http://` than `file://`).

## 📦 Deployment

This site is deployed with **GitHub Pages**, served from the `main` branch, root folder.
